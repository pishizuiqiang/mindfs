## 主题系统详细功能

### 1. 外观模式切换
```typescript
// 支持三种模式
type AppearanceMode = 'light' | 'dark' | 'follow-system';

// 切换功能
setAppearanceMode(mode: AppearanceMode): void;

// 获取当前模式
getAppearanceMode(): AppearanceMode;

// 监听模式变化
APPEARANCE_CHANGE_EVENT: string
```

### 2. 系统集成
- **启动时应用**: `applyAppearanceMode()` 在应用启动时立即应用主题
- **跨标签同步**: 通过 localStorage 和 storage 事件实现跨标签同步
- **实时切换**: 无需刷新即可切换主题

### 3. UI 组件适配
- **CSS 变量**: 使用 CSS 自定义属性支持主题切换
- **组件响应**: FileTree 等组件已适配主题变化
- **菜单集成**: 主题切换菜单已集成到文件树中
