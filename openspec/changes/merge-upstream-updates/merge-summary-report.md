## 未集成的功能及原因

### Batch 3 其他 UI 改进 🟡
- **功能**: 历史消息编辑、代码块复制、搜索导航改进等
- **原因**: 复杂的 React 组件冲突，性价比相对较低
- **影响**: 可用性影响有限，核心功能已具备

### Batch 4 Git 工作流集成 🟡
- **功能**: Git 分支查看、Git worktree 支持、项目重命名等
- **原因**: 涉及大量文件系统操作和多文件冲突，复杂度极高
- **影响**: 工作流增强功能缺失，但不影响基本使用

### Batch 5 Android 和新功能 🔴
- **功能**: 新 Agent 支持、命令执行模式、Android 功能增强、E2EE 增强
- **原因**: 复杂度最高，涉及 Android 构建和新架构
- **影响**: 高级功能缺失，但核心功能完整
